# burgr-sample-mini

[![CI](https://github.com/SolidOps/burgr-sample-mini/actions/workflows/ci.yml/badge.svg)](https://github.com/SolidOps/burgr-sample-mini/actions/workflows/ci.yml)

> *The AI writes the model, a deterministic generator writes the code, the tests decide.*

A minimal ASP.NET Core API generated by [Burgr](https://github.com/SolidOps/burgr) from a
YAML model, with Burgr's default template set, **Mini** (Minimal API + EF Core, one
project, public packages only), and the harness that keeps AI agents on the model and the
extension points.

## Run it

Requires the .NET 10 SDK.

```sh
dotnet tool restore          # burgr, pinned in dotnet-tools.json
dotnet burgr specs           # regenerates src/Library/**/*.g.cs from specs/library.yaml
dotnet test Library.slnx
dotnet run --project src/Library
```

Then `GET /authors`, `POST /books`… The CI regenerates the code and fails if it differs
from the committed files: generation is deterministic.

## What is where

| Path | Written by | Content |
|---|---|---|
| `specs/burgr.json` | hand | Three settings: no template source means the Mini set, downloaded from nuget.org at burgr's version. |
| `specs/library.yaml` | hand | The model: authors and books, a book status enum, a reference, a navigation, a calculated property. |
| `src/Library/**/*.g.cs` | burgr | Domain classes, DTOs, `DbContext`, CRUD endpoints. Never edited by hand. |
| `src/Library/Program.cs` | hand | SQLite, schema creation, `app.MapLibraryEndpoints()`. |
| `src/Library/Domain/Book.cs` | hand | `CalculateIsAvailable()`, the calculated property of the model. |
| `src/Library/Contracts/BookInput.cs` | hand | A validation rule of its own (`OnValidating`). |
| `src/Library.Tests/` | hand | Integration tests through the real endpoints. |
| `AGENTS.md`, `CLAUDE.md`, `.claude/` | burgr (`/harness:.`) | The harness: what an AI agent may write, what it must not read or edit, how to test. A hook refuses reads and edits of generated files. |

## Change the model

Edit `specs/library.yaml`, run `dotnet burgr specs`, build: the compiler asks for the
extension points the change requires. [`AGENTS.md`](AGENTS.md) lists what the Mini set
supports and generates.
